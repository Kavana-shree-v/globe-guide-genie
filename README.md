# 🌍 Globe Guide Genie

Globe Guide Genie is a modern, interactive web application designed to simplify travel planning. Created and built using **[Lovable](https://lovable.dev)**, this application features custom travel guide scaffolding, dynamic budget calculation, and rich visual guides for worldwide destinations.

## ✨ Features

- **Prompt-Driven Architecture:** Generated and iterated seamlessly via Lovable prompt engineering.
- **Budget Calculator:** Plan and estimate travel expenses with an intuitive UI.
- **Travel Guide Scaffolding:** Discover curated guide structures and travel itineraries.
- **Interactive Visuals:** Built-in travel media integration for immersive exploration.
- **Responsive Design:** Optimized across desktop, tablet, and mobile views.
